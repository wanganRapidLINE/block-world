# Block World

ワールドルール（[tetrisch](https://tetrisch.github.io/main/rule.html)）準拠の落ちものパズルです。

**遊ぶ: https://wanganrapidline.github.io/block-world/**

スマホの Chrome で開き、メニューの「ホーム画面に追加」（または「インストール」）でアプリとして使えます。一度開けば BGM も含めて保存されるので、電波のない場所でも遊べます。
TypeScript + Vite で作った PWA で、PC（Windows）とスマホ（Android）のブラウザで同じものが動きます。

## 起動方法

```bash
npm install        # 初回のみ
npm run dev        # 開発サーバー → http://localhost:5173 をブラウザで開く
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー（PCだけで遊ぶ・確認する） |
| `npm run dev:lan` | LAN内に HTTPS で公開（スマホで確認する。下記参照） |
| `npm test` | ルール部分（`src/core`）と長押し処理の自動テスト |
| `npm run build` | 型チェック＋本番用ビルド（`dist/` に出力） |
| `npm run preview` | ビルドしたものを http://localhost:4173 で確認 |
| `npm run generate-icons` | `public/icon.svg` から PWA 用アイコンを作り直す |

## モード

| モード | 内容 |
|---|---|
| マラソン | 150ラインを消したらゲームクリア。クリア時間も表示 |
| エンドレス | ゲームオーバーになるまで続く（LEVEL 15 以降は速度そのまま）。開始レベルを 1〜15 から選べる |

タイトル画面でモードと開始レベルを選んでから「スタート」で始めます。

- タッチ・マウス：モードのボタンを押して選ぶ（押しただけでは始まらない）。開始レベルは「−」「＋」（マラソン中は薄く表示され、変更できない）
- コントローラー・キーボード：十字キー（←→）の左右でモード、上下（↑↓）で開始レベル、Options(+) / Enter でスタート
- 最後に選んだモードと開始レベルを覚えています。

## 操作方法（初期設定）

割り当てはタイトル画面・ポーズ画面の「設定」から変更できます（ブラウザに保存されます）。

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 左右移動 | ← → / A D | 十字キー ← → / 左スティック |
| ソフトドロップ | ↓ / S | 十字キー ↓ / 左スティック ↓ |
| ハードドロップ | ↑ / W | 十字キー ↑ / 左スティック ↑ |
| 右回転 | Space / J | 右ボタン（DS4の○、8BitDoのA） |
| 左回転 | K | 下ボタン（DS4の×、8BitDoのB） |
| HOLD | U / Shift | L1 / R1 |
| ポーズ・決定 | P / Esc / Enter | Options / + |

- 以前の単一HTML版にあった「Ctrl で HOLD」は外しました。Ctrl を押しながら W（ハードドロップ）を押すと、ブラウザのタブが閉じてしまうためです。
- ゲームパッドは、ページを開いたあとにどれかボタンを押すとブラウザに認識されます（Firefox・Chrome 共通の仕様）。
- 8BitDo Micro（Android・standard mapping）は、十字キーがボタンではなくスティック（軸0・軸1）として届きます。そのため左スティックの上下左右も初期設定で十字キーと同じ操作にしています。
- 8BitDo Micro は接続モードによってボタン番号が変わります。思ったとおりに動かないときは、設定画面で割り当て直してください。キーボードモードで接続した場合は、キーボードとして扱われます。
- 横向き（タブレットなど）では、仮想パッドがフィールドの左右に出ます。ホーム画面に追加したアプリも、画面の向きは固定していません。
- タッチ画面では、仮想パッドが画面下に出ます。ゲームパッドをつなぐと自動で隠れます（設定で「常に表示」「常に隠す」も選べます）。
- 遊んでいる間はスマホがスリープしないようにしています（Screen Wake Lock。HTTPS でのみ有効）。

## BGM

- `bgm/` フォルダの mp3 を、ファイル名順のプレイリストとして流します（1曲終わったら次の曲、最後まで行ったら最初に戻る）。mp3 を足せば自動で加わります。
- ゲーム開始で次の曲を頭から再生、ポーズで一時停止、ゲームオーバーでフェードアウトします。
- 設定画面の「BGMを流す」をOFFにすると、BGMを一切再生しません（自分の好きな音楽をかけながら遊ぶ用）。音量も設定画面で変えられます。
- ブラウザの制限で、画面のクリックやキー入力の前には音が出せません。ゲームパッドのボタンだけで開始して無音のときは、画面を一度クリック（タップ）してください。

## 効果音

- 音声ファイルは使わず、Web Audio API でその場で電子音を作って鳴らしています（`src/audio/sfx.ts`）。
- 鳴るのは移動・回転・HOLD・固定・ハードドロップ・ライン消去（1〜3ライン／テトリス）・T-Spin・Back-to-Back・レベルアップ・ゲームオーバーです。
- 設定画面で ON/OFF と音量を変えられます。OFF のときは音声機能そのものを起動しません。

## ルール仕様

| 項目 | 内容 |
|---|---|
| フィールド | 10×20。上に20行の見えないバッファがあり、上2行分だけ描画 |
| ツモ | 7種1巡（7-bag） |
| NEXT / HOLD | NEXT 5個（1個目は黄色い枠で大きく、2個目以降は小さめに表示）。HOLDは1個で、次のミノが固定されるまで再使用不可 |
| 回転 | SRS（スーパーローテーションシステム）。JLSTZ用とI用のキックテーブル |
| ロックダウン | 接地から0.5秒で固定。移動・回転で猶予が戻るのは15回まで。より低い段に落ちると回数もリセット |
| 落下速度 | ガイドラインの式 `(0.8 − (Lv−1)×0.007)^(Lv−1)` 秒/段。10ラインごとにLvアップ（最大15） |
| ソフトドロップ | 重力の20倍、1段1点。接地しても即固定はしない |
| ハードドロップ | 1段2点、即固定。落ちた軌跡にうっすら残像（0.22秒） |
| T-Spin | 3コーナー判定。向いている側の2角が埋まっていれば T-Spin、1つなら Mini。5番目のキックで入った場合は T-Spin |
| 得点（×Lv） | Single 100 / Double 300 / Triple 500 / Tetris 800、T-Spin 400・Single 800・Double 1200・Triple 1600、Mini 100・Single 200・Double 400 |
| B2B | Tetris とライン消去を伴う T-Spin が連続すると1.5倍 |
| REN | 50 × REN数 × Lv |
| ライン消去 | そろった行が光り、中央から消える演出（0.4秒）。演出中は落下・操作・HOLDが止まる |
| ゲームクリア | マラソンのみ。150ライン目を消した演出のあとでクリア（超えた分のラインもそのまま数える） |
| ゲームオーバー | 出現位置がふさがっている / 可視範囲より完全に上で固定した |

## 公開（GitHub Pages）

- `main` ブランチに push すると、GitHub Actions がテスト・ビルドして自動で公開します（`.github/workflows/deploy.yml`）。
- 公開版を更新すると、スマホ側は次に開いたとき（またはその次）に新しい版へ切り替わります。

## 開発中のスマホでの確認方法

Gamepad API と PWA は HTTPS でしか動かないため、`dev:lan` で自己署名証明書を使います。

1. PC で `npm run dev:lan` を実行し、表示される `https://192.168.x.x:5173/` を確認する
   - Windows ファイアウォールの許可ダイアログが出たら、「プライベートネットワーク」のみ許可する
2. スマホ（同じWi-Fi）の Chrome でその URL を開く
3. 「この接続ではプライバシーが保護されません」と出るので「詳細設定」→「アクセスする」
4. 8BitDo Micro をスマホに Bluetooth 接続し、ボタンを1回押す

※ 自己署名証明書では Service Worker が動かないので、オフライン動作は公開版で確認してください。

## ファイル構成

```
src/
  core/      ルール本体（画面・入力に依存しない。tests/ で自動テスト）
    pieces.ts      ミノの形・色・SRSキックテーブル
    randomizer.ts  7-bag
    board.ts       フィールド・当たり判定・ライン消去
    game.ts        出現・移動・回転・重力・ロックダウン・HOLD・ゲームオーバー
    tspin.ts       T-Spin 判定
    scoring.ts     得点・B2B・REN・落下速度
  input/     キーボード・ゲームパッド・タッチ入力、割り当ての保存、DAS/ARR
  render/    Canvas 描画
  ui/        設定画面
  main.ts    画面遷移とゲームループ
```
